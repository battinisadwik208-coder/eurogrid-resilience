# EuroGrid

EuroGrid is an AI-assisted resilience coordination layer for Europe. It helps communities, utilities, transport operators, and local authorities understand how a disruption in one region can affect essential services elsewhere.

## MunichTech EXPO fit
MunichTech EXPO asks builders to build what Europe needs. EuroGrid targets a practical European problem: essential infrastructure crosses municipal and national borders, while crisis updates remain fragmented. The prototype shows a shared situation board and a human-reviewable prioritisation briefing.

## Prototype
Open `index.html` in a browser. The demo uses a fixed regional scenario so it works without credentials or external APIs. The production architecture would connect approved public feeds, operator updates, and dependency maps through a permissioned event pipeline.

## Technology
- Semantic HTML, CSS, and vanilla JavaScript
- Explainable prioritisation interface
- Planned production layer: event normalisation, graph-based dependency analysis, multilingual language-model briefings, role-based access, and audit logs

## Responsible deployment
EuroGrid recommends actions but never executes an operational change automatically. Every briefing carries confidence and source context, and a responsible human must confirm warnings and decisions.
